Une clé API autorise les requêtes vers Aivrae. Utilisez des clés séparées pour les applications, environnements ou clients afin de limiter, faire tourner et désactiver chaque accès indépendamment.

- Ne publiez jamais une clé de production dans du code frontend, GitHub, des logs publics ou des captures.
- Utilisez une clé à faible quota pour les tests.
- Si une clé fuit, désactivez-la immédiatement et créez-en une nouvelle.
- Pour le support, fournissez seulement le nom ou le suffixe de la clé.
