Si la sélection de groupe est disponible, choisissez le groupe par défaut lors de la création d'une clé ou suivez les paramètres indiqués dans la console.

- Ouvrez la page des clés API.
- Créez une clé nommée clairement, par exemple production, test ou client-a.
- Sélectionnez groupe, quota ou permissions si disponibles.
- Stockez la clé dans des variables d'environnement ou un gestionnaire de secrets.
- Vérifiez l'accès avec /v1/models ou une courte requête chat.
