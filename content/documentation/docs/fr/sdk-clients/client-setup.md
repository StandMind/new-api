La plupart des clients tiers utilisent OpenAI Compatible Provider. Les noms de champs varient, mais les valeurs clés sont API Key, Base URL et Model.

| Client | Type fournisseur | Base URL | Notes |
| --- | --- | --- | --- |
| Cherry Studio | OpenAI Compatible | https://aivrae.com/v1 | Copiez le modèle depuis la console. |
| ChatBox | OpenAI API Compatible | https://aivrae.com/v1 | Faites d'abord un court test. |
| Cursor / Cline | OpenAI Compatible / Custom Provider | https://aivrae.com/v1 | Utile pour le code et les agents. |
| Dify | OpenAI-API-compatible | https://aivrae.com/v1 | Ajoutez chat et embedding séparément. |
| LobeChat / NextChat | Endpoint OpenAI personnalisé | https://aivrae.com/v1 | Endpoint complet seulement si requis. |
| Aider / Claude Code | OpenAI compatible ou protocole natif | https://aivrae.com/v1 | Claude natif : /v1/messages ; Gemini natif : /v1beta/models/{model}:generateContent. |
