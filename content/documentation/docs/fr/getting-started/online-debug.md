Avant l'intégration en production, utilisez le testeur intégré pour vérifier la clé, le modèle, la Base URL et le solde.

- Créez une clé API et copiez un modèle disponible depuis la console.
- Renseignez la clé dans le testeur et modifiez le modèle si nécessaire.
- Envoyez la requête et vérifiez le code d'état et la sortie du modèle.
- Pour ChatBox, Cherry Studio, Postman ou curl, réutilisez la Base URL et le corps de requête affichés.
- Choisissez le mode OpenAI Compatible lorsqu'il est disponible.
- Évitez les contrôles de santé fréquents sur de grands modèles, car ils consomment des crédits.
