Séquence recommandée pour votre premier appel texte.

- Inscrivez-vous et connectez-vous à la console Aivrae.
- Rechargez ou vérifiez le solde disponible.
- Créez une clé API.
- Si des groupes sont proposés, commencez par le groupe recommandé.
- Utilisez https://aivrae.com/v1 comme Base URL et envoyez une requête.

```
{
  "base_url": "https://aivrae.com/v1",
  "api_key": "YOUR_AIVRAE_API_KEY",
  "model": "MODEL_NAME"
}
```
