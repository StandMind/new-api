API key dùng để xác thực yêu cầu tới Aivrae. Hãy dùng key riêng cho từng ứng dụng, môi trường hoặc khách hàng để dễ giới hạn, xoay vòng và vô hiệu hóa.

- Không công khai production key trong frontend, GitHub, log công khai hoặc ảnh chụp.
- Môi trường test nên dùng key giới hạn thấp.
- Nếu key bị lộ, hãy vô hiệu hóa ngay và tạo key mới.
- Khi liên hệ hỗ trợ, chỉ cung cấp tên hoặc hậu tố key.
