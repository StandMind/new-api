Nếu có chọn nhóm, hãy chọn nhóm mặc định khi tạo key hoặc làm theo hướng dẫn trong console.

- Mở trang API key trong console.
- Tạo tên rõ ràng như production, test hoặc client-a.
- Chọn nhóm, quota hoặc quyền mô hình nếu có.
- Lưu key trong biến môi trường backend hoặc secret manager.
- Kiểm tra bằng /v1/models hoặc một yêu cầu chat ngắn.
