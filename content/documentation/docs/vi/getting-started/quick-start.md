Thực hiện lần gọi mô hình văn bản đầu tiên theo thứ tự sau.

- Đăng ký và đăng nhập console Aivrae.
- Nạp hoặc xác nhận còn tín dụng trả trước.
- Tạo API key.
- Nếu có nhóm định tuyến, bắt đầu với nhóm mặc định hoặc được khuyến nghị.
- Đặt Base URL là https://aivrae.com/v1, sao chép tên mô hình và gửi yêu cầu.

```
{
  "base_url": "https://aivrae.com/v1",
  "api_key": "YOUR_AIVRAE_API_KEY",
  "model": "MODEL_NAME"
}
```
