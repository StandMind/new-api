Trước khi tích hợp production, hãy dùng bộ kiểm thử trên trang để kiểm tra key, tên mô hình, Base URL và số dư.

- Tạo API key và sao chép tên mô hình khả dụng trong console.
- Nhập API key vào bộ kiểm thử, đổi tên mô hình nếu cần.
- Gửi yêu cầu và xác nhận vùng phản hồi có mã trạng thái và đầu ra mô hình.
- Với ChatBox, Cherry Studio, Postman hoặc curl, có thể dùng lại Base URL và body trong tài liệu.
- Ưu tiên chế độ OpenAI Compatible nếu có.
- Không chạy health check tần suất cao trên mô hình lớn vì sẽ tiêu hao tín dụng.
