価格差は通常、モデルルート、アカウントプール、並列性、安定性、地域、モデル権限に由来します。Aivrae コンソールにグループが表示される場合は、コンソールが正です。

| グループ | 用途 | 価格 / 安定性 |
| --- | --- | --- |
| デフォルト | テストと通常チャット | コストと可用性のバランス。 |
| 高安定 | 本番と顧客向けサービス | コストは高め、安定性が高い。 |
| 低コスト | 非重要タスクや batch | 低コストだが制限や変動あり。 |
| Claude / Gemini / local | 特定モデルファミリー | 倍率や権限が分かれる場合あり。 |

> 同じモデルでもグループによって価格が異なる場合があります。モデルページ、キー設定、利用ログを正としてください。
