# 返金ポリシー

最終更新日：2026年5月16日。本ポリシーは Aivrae プリペイドクレジットの返金リクエストの審査方法を説明します。

## 基本方針

Aivrae は API 利用のためのプリペイドクレジットを販売します。返金は個別に審査されます。API リクエストで既に消費されたクレジットは、サービスコストが発生している可能性があるため、通常返金できません。

## 返金対象になり得るケース

重複支払い、クレジット未反映、請求ミス、購入直後の未使用クレジットに関するリクエストは審査対象になる場合があります。

## 通常返金できないケース

消費済み API クレジット、ポリシー違反、停止済みアカウント、未対応の第三者クライアント、無効なプロンプト、モデルサービスの制限は通常返金できません。

## 返金申請方法

アカウントメール、取引番号、希望金額、理由を添えて support@aivrae.com までメールしてください。通常 3 営業日以内の確認を目指します。
