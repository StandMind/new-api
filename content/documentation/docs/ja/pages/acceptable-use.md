# 許容利用ポリシー

最終更新日：2026年5月16日。本ポリシーは、API リクエスト、アカウント、クレジット、連携を含む Aivrae のすべての利用に適用されます。

## 原則

Aivrae は合法かつ許可された AI API 利用のために設計されています。利用者は、プロンプト、出力、連携、下流での利用が適用法および第三者モデルプロバイダーのポリシーに準拠していることを確認する責任があります。

## 禁止行為

違法行為、詐欺、フィッシング、スパム、マルウェア、認証情報窃取、不正アクセス、ポルノ、性的に露骨なコンテンツまたは NSFW コンテンツ、未成年者に関する性的コンテンツ、同意のない親密コンテンツ、ヘイト、脅迫、暴力、自傷指示、プロバイダー制限の回避は禁じられています。

## 執行

本ポリシーに違反するアカウントや API キーに対して、レート制限、停止、終了を行う場合があります。必要に応じて記録を保存し、決済事業者、第三者モデルプロバイダー、合法的な要請に協力することがあります。

## 不正利用の報告

不正利用の疑いは support@aivrae.com まで報告してください。可能であれば、関連するアカウント、リクエスト、取引情報を含めてください。
