# プライバシーポリシー

最終更新日：2026年5月16日。本ポリシーは、ウェブサイト、コンソール、API ゲートウェイ利用時に Aivrae が情報を収集、利用、保護する方法を説明します。

## 収集する情報

アカウント情報、認証データ、請求およびクレジット記録、API キー、リクエストメタデータ、利用ログ、デバイス情報、サポート連絡内容を収集します。

## 情報の利用

サービス提供、ユーザー認証、クレジット処理、API 利用計測、不正利用防止、問題調査、信頼性向上、法的義務の履行に情報を利用します。

## API コンテンツと第三者モデルプロバイダー

API リクエストは Aivrae が選択する第三者モデルプロバイダーにルーティングされる場合があります。各プロバイダーは自社の規約とプライバシー慣行に従ってリクエスト内容を処理することがあります。

## データ保持

サービス運営、紛争解決、ポリシー適用、法律または会計上の要件を満たすために必要な期間、アカウントおよび利用記録を保持します。

## 利用者の選択

アカウント情報へのアクセス、訂正、削除を希望する場合はお問い合わせください。ただし、セキュリティ、不正防止、法令、請求記録の要件により制限される場合があります。
