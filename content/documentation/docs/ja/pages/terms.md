# 利用規約

最終更新日：2026年5月16日。本規約は、Aivrae のウェブサイト、コンソール、API ゲートウェイ、プリペイドクレジットおよび関連サービスの利用に適用されます。

## サービス

Aivrae は、互換モデル API へのアクセス、API キー管理、利用状況確認、プリペイド残高の消費を支援するホスト型 AI API ゲートウェイを提供します。明示されない限り、Aivrae は第三者基盤モデルの作成者ではありません。

## プロバイダーとの関係

Aivrae は対応する第三者 AI モデルへの独立した API ゲートウェイアクセスを提供します。OpenAI、Anthropic、Google、その他の第三者モデルプロバイダーの公式製品、関連会社、または推奨サービスではありません。

## アカウントとセキュリティ

アカウントおよび API キーで行われる活動については利用者が責任を負います。認証情報を安全に管理し、不正アクセスの疑いがある場合は連絡してください。不正利用、支払い紛争、ポリシー違反に関わるアカウントは停止される場合があります。

## 支払いとクレジット

プリペイドクレジットは支払い成功後に追加され、対象 API 利用で消費されます。消費量はモデル、トークン数、リクエスト種別、設定された料金によって決まります。クレジットは Aivrae サービス外の保存金銭価値ではありません。

## 許容される利用

利用者は当社の許容利用ポリシーおよび第三者モデルプロバイダーの規則を遵守する必要があります。違法行為、不正利用、スパム、認証情報の窃取、マルウェア、法律またはプロバイダーポリシーに反する内容に Aivrae を使用することはできません。

## 可用性と変更

サービスはメンテナンス、第三者モデルプロバイダーの制限、ネットワーク問題、ポリシー変更の影響を受ける場合があります。必要に応じて、モデル、料金、ルーティング規則、機能を更新することがあります。
