アプリケーションは一般的なステータスコードを明示的に処理し、backend にエラーを記録してください。

| ステータス | 意味 | 対応 |
| --- | --- | --- |
| 400 | 本文、パラメータ、JSON が不正 | 本文、endpoint、パラメータを確認。 |
| 401 | キーなし、誤り、期限切れ、無効 | キーとヘッダーを確認。 |
| 403 | モデル、グループ、機能の権限なし | 権限、プラン、グループを確認。 |
| 404 | パスまたはモデル不明 | Base URL、native path、model を確認。 |
| 413 | 本文またはコンテキスト過大 | messages、contents、input を短くする。 |
| 429 | レート、同時実行、クォータ、残高制限 | 並列数を下げ、残高確認。 |
| 500 / 502 / 503 | 一時的な Aivrae またはモデルサービスエラー | 後で再試行。継続時はサポートへ。 |
