Balance, usage, and deductions should be checked in the Aivrae console. To protect your account, use the signed-in console for sensitive information and never submit a full production key on a page that is not officially operated by Aivrae.

- Check account balance and recharge records.
- Review request time, model, input/output tokens, cost, and status code.
- For billing investigations, keep request time, key name, model name, and error message.
- When contacting support, provide the key name or suffix instead of the full key.
