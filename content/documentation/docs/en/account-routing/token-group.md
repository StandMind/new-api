If group selection is enabled, choose the default group when creating a key or use the group parameter documented in the console.

- Open the API key page in the console.
- Create a key with a clear name such as production, test, or client-a.
- Select group, quota, or model permissions when available.
- Store the key in backend environment variables or a secret manager.
- Verify model access with /v1/models or a short chat request.
