## Обзор платформы

Aivrae — агрегирующий AI API gateway для международных разработчиков и команд. Он предоставляет единый endpoint, управление API-ключами, доступ к моделям, учет предоплаченных кредитов и журналы запросов. Можно использовать OpenAI-совместимые форматы, Responses API, embeddings, а также нативные форматы Claude и Gemini.

Публичная документация описывает текстовые сервисы. Доступность функций определяется консолью, ответами API и официальной поддержкой Aivrae.

## Основные возможности

- Единый доступ: Base URL `https://aivrae.com/v1` для OpenAI-совместимых запросов.
- Совместимость протоколов: OpenAI-совместимый формат рекомендуется по умолчанию; также есть Claude Messages и Gemini generateContent.
- Переключение моделей: используйте имена моделей из консоли.
- Учет использования: баланс, история, расход и ошибки доступны в консоли.
- Встроенное тестирование: страницы API содержат готовые примеры запросов.

## Рекомендуемый порядок

1. Войдите в консоль Aivrae.
2. Создайте API-ключ и скопируйте доступное имя модели.
3. Выполните небольшой запрос через встроенный тестер.
4. Укажите Base URL `https://aivrae.com/v1`.
5. В production логируйте request ID, статус, модель и ошибку.

## Сравнение использования

| Пункт | С Aivrae | Отдельные интеграции |
| --- | --- | --- |
| Endpoint | Один OpenAI-совместимый Base URL и отдельные нативные текстовые endpoints | Нужно поддерживать несколько endpoints |
| API-ключ | Управление в одной консоли | Отдельное управление для каждого сервиса |
| Совместимость клиентов | Работает с большинством OpenAI-compatible клиентов | Нужна настройка под каждый сервис |
| Смена модели | Проверяйте доступные модели, меняя имя модели | Часто требуется менять endpoint и параметры |
| Журналы использования | Собраны в консоли | Разнесены по разным панелям |
| Тестирование документации | Тестируйте текущий endpoint прямо на странице | Обычно нужен Postman или собственный код |

## Область документации

| Возможность | Статус | Примечания |
| --- | --- | --- |
| Текстовый чат | Поддерживается | `/v1/chat/completions`. |
| Streaming | Поддерживается | `stream: true` и чтение SSE. |
| Function calling / JSON | Зависит от модели | Нужна поддержка `tools` и `response_format`. |
| Responses API | Поддерживается | `/v1/responses`. |
| Embeddings | Поддерживается | RAG, поиск, сходство. |
| Claude native | Зависит от модели | `/v1/messages`, обычно только Claude. |
| Gemini native | Зависит от модели | `/v1beta/models/{model}:generateContent`, обычно только Gemini. |
