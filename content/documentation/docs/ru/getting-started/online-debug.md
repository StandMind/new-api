Перед production-интеграцией выполните небольшой запрос во встроенном тестере, чтобы проверить ключ, модель, Base URL и баланс.

- Создайте API-ключ и скопируйте имя модели из консоли.
- Введите ключ в тестер и при необходимости измените модель.
- Отправьте запрос и проверьте статус и ответ модели.
- Для ChatBox, Cherry Studio, Postman или curl используйте те же Base URL и тело запроса.
- При наличии выбирайте режим OpenAI Compatible.
- Не запускайте частые health-check запросы к большим моделям: они расходуют кредиты.
