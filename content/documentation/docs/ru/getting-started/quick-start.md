Последовательность для первого текстового вызова.

- Зарегистрируйтесь и войдите в консоль Aivrae.
- Пополните баланс или убедитесь, что кредиты доступны.
- Создайте API-ключ.
- Если есть группы маршрутизации, начните с группы по умолчанию.
- Укажите Base URL https://aivrae.com/v1, скопируйте модель и отправьте запрос.

```
{
  "base_url": "https://aivrae.com/v1",
  "api_key": "YOUR_AIVRAE_API_KEY",
  "model": "MODEL_NAME"
}
```
