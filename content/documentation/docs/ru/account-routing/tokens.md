API-ключ авторизует запросы к Aivrae. Используйте отдельные ключи для приложений, сред и клиентов, чтобы независимо ограничивать, менять и отключать доступ.

- Не публикуйте production-ключи во frontend-коде, GitHub, публичных логах или скриншотах.
- Для тестов используйте отдельный ключ с малым лимитом.
- При утечке ключа сразу отключите его и создайте новый.
- Для поддержки указывайте только имя или суффикс ключа.
