Большинство сторонних клиентов подключаются как OpenAI Compatible Provider. Названия полей отличаются, но основные значения — API Key, Base URL и Model.

| Клиент | Тип | Base URL | Примечания |
| --- | --- | --- | --- |
| Cherry Studio | OpenAI Compatible | https://aivrae.com/v1 | Модель из консоли. |
| ChatBox | OpenAI API Compatible | https://aivrae.com/v1 | Сначала короткий тест. |
| Cursor / Cline | OpenAI Compatible / Custom Provider | https://aivrae.com/v1 | Код и agent-задачи. |
| Dify | OpenAI-API-compatible | https://aivrae.com/v1 | Добавляйте chat и embeddings отдельно. |
| LobeChat / NextChat | Custom OpenAI endpoint | https://aivrae.com/v1 | Полный endpoint только если требуется. |
| Aider / Claude Code | OpenAI compatible или native | https://aivrae.com/v1 | Claude: /v1/messages; Gemini: /v1beta/models/{model}:generateContent. |
