## 平台简介

Aivrae 是面向全球开发者和团队的 AI API 聚合网关，提供统一的接口地址、API Key 管理、模型调用、额度计费和用量记录。你可以通过兼容 OpenAI 的请求格式接入文本聊天、文本生成、向量化、Responses API、Claude 原生文本格式和 Gemini 原生文本格式，减少为不同模型服务分别编写适配代码的成本。

当前公开文档聚焦文本类型服务。可用功能以控制台展示、接口响应和 Aivrae 官方支持回复为准。

## 核心能力

- 统一接入：使用 `https://aivrae.com/v1` 作为 OpenAI 兼容 Base URL，并通过控制台创建的 API Key 发起请求。
- 协议兼容：默认推荐 OpenAI 兼容格式，也提供 Claude Messages 和 Gemini generateContent 原生格式示例。
- 模型切换：以控制台展示的模型名称为准，通过修改 `model` 字段或原生接口路径切换可用模型。
- 额度管理：在控制台查看余额、请求记录、模型消耗和异常状态。
- 在线调试：文档中的接口页面带有默认请求值，填写 API Key 后即可测试当前接口。

## 推荐接入流程

1. 注册并登录 Aivrae 控制台。
2. 创建 API Key，并复制一个控制台可见的模型名称。
3. 在文档的在线调试框中先发送一次小额度请求。
4. 将应用或客户端的 Base URL 设置为 `https://aivrae.com/v1`。
5. 在生产环境中记录请求 ID、状态码、模型名和错误消息，便于排障和核对用量。

## 使用方式对比

| 项目 | 使用 Aivrae | 分别接入多个模型服务 |
| --- | --- | --- |
| 接口地址 | 统一 OpenAI 兼容 Base URL，并提供部分原生格式入口 | 需要维护多个服务地址 |
| API Key | 一个控制台集中管理 | 每个服务分别管理 |
| 客户端兼容 | 兼容多数 OpenAI 格式客户端 | 需要按服务分别配置 |
| 模型切换 | 修改模型名称即可测试可用模型 | 通常需要适配不同接口和参数 |
| 用量记录 | 控制台集中查看 | 分散在不同服务后台 |
| 文档调试 | 当前接口页可直接测试 | 通常需要单独配置 Postman 或代码 |

## 当前文档范围

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 文本聊天 | 支持 | 使用 `/v1/chat/completions`。 |
| 流式输出 | 支持 | 设置 `stream: true`，客户端按 SSE 增量读取。 |
| 函数调用 / JSON 输出 | 文本范围支持 | 取决于所选模型是否支持 `tools` 与 `response_format`。 |
| Responses API | 支持 | 使用 `/v1/responses`，适合新版 OpenAI 兼容工作流。 |
| Embeddings | 支持 | 用于 RAG、语义检索、相似度和聚类。 |
| Claude 原生文本格式 | 按模型支持 | 使用 `/v1/messages`，通常只适用于 Claude 模型。 |
| Gemini 原生文本格式 | 按模型支持 | 使用 `/v1beta/models/{model}:generateContent`，通常只适用于 Gemini 模型。 |
