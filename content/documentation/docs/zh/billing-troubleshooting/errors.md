接入方应对常见状态码做明确处理，并把服务返回的错误消息记录到后端日志中。

| 状态码 | 含义 | 建议处理 |
| --- | --- | --- |
| 400 Bad Request | 请求格式错误、参数不支持、JSON 无法解析 | 检查请求体、模型接口兼容性和参数名。 |
| 401 Unauthorized | API Key 缺失、错误、过期或被禁用 | 重新复制 Key，确认请求头格式。 |
| 403 Forbidden | 账号无权限访问模型、分组或功能 | 检查模型权限、套餐和令牌分组。 |
| 404 Not Found | 路径错误或模型不存在 | 确认 Base URL、原生接口路径和 model 名称。 |
| 413 Request Entity Too Large | 请求体过大或上下文过长 | 缩短 messages、contents 或输入体积。 |
| 429 Too Many Requests | 频率、并发、额度限制或余额不足 | 降低并发、检查余额，使用退避重试。 |
| 500 / 502 / 503 | Aivrae 或模型服务临时异常 | 短暂等待后重试，持续失败请联系支持。 |
