# 退款政策

最后更新：2026-05-16。本政策说明我们如何审核 Aivrae 预付费额度的退款请求。

## 总体政策

Aivrae 销售用于 API 使用的预付费额度。退款会按具体情况审核。已经被 API 请求消耗的额度通常不予退款，因为服务成本可能已经产生。

## 可能符合条件的退款

重复支付、额度未到账、账单错误，或购买后短时间内提出的未使用额度退款请求，可以提交审核。

## 通常不可退款的情况

已经消耗的 API 额度、违反政策导致的账号处理、被暂停账号、第三方客户端问题、无效提示词或模型服务限制，通常不予退款。

## 如何申请退款

请发送邮件至 support@aivrae.com，并提供账号邮箱、交易编号、申请金额和原因。我们会尽量在 3 个工作日内审核退款请求。
