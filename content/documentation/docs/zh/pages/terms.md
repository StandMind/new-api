# 服务条款

最后更新：2026-05-16。本条款适用于你对 Aivrae 网站、控制台、API 网关、预付费额度和相关服务的使用。

## 服务内容

Aivrae 提供托管的 AI API 网关，帮助用户访问兼容模型 API、管理 API Key、查看用量并消耗预付费账号额度。除非另有说明，Aivrae 并不是第三方基础模型的创建方。

## 服务商关系

Aivrae 提供对受支持第三方 AI 模型的独立 API 网关访问服务，并非 OpenAI、Anthropic、Google 或其他第三方模型服务商的官方产品，也未获得其关联或背书。

## 账号与安全

你需要对账号和 API Key 下的所有活动负责。你应妥善保管凭证，并在发现异常访问时及时联系支持。如果账号涉及滥用、支付争议或违反政策，我们可能暂停服务。

## 支付与额度

支付成功后，预付费额度会加入你的账号，并在合规 API 请求中消耗。额度消耗取决于模型、Token 数量、请求类型和后台计费规则。额度仅用于 Aivrae 服务，不代表站外储值货币。

## 可接受使用

你必须遵守我们的可接受使用政策和第三方模型服务商规则。不得将 Aivrae 用于违法活动、滥用、垃圾信息、盗取凭证、恶意软件或违反法律及相关服务政策的内容。

## 可用性与变更

服务可能受到维护、第三方服务限制、网络问题或政策变化影响。我们可能根据需要调整模型、费率、路由规则或产品功能。
