# 隐私政策

最后更新：2026-05-16。本政策说明 Aivrae 在你使用网站、控制台和 API 网关时如何收集、使用和保护信息。

## 我们收集的信息

我们会收集账号信息、认证数据、账单和额度记录、API Key、请求元数据、用量日志、设备信息和支持沟通记录。

## 我们如何使用信息

我们使用信息来提供服务、认证用户、处理额度、计量 API 用量、防止滥用、排查问题、提升可靠性并履行法律义务。

## API 内容和第三方模型服务商

API 请求可能被路由到 Aivrae 选择的第三方模型服务商。这些服务商可能根据自己的条款和隐私实践处理请求内容。

## 数据保留

我们会在运营服务、解决争议、执行政策和满足法律或会计要求所需期间保留账号和用量记录。

## 你的选择

你可以联系我们请求访问、更正或删除账号信息，但可能受安全、反欺诈、法律和账单记录要求限制。
