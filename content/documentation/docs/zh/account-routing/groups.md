中转站的价格差异通常来自模型渠道、账号池、并发能力、稳定性、地域和模型权限。Aivrae 如在控制台提供分组，请以控制台实际展示为准。

| 分组类型 | 适合场景 | 价格/稳定性特点 |
| --- | --- | --- |
| 默认分组 | 日常测试、普通文本对话 | 优先推荐新用户使用，兼顾可用性和成本。 |
| 高稳定分组 | 生产业务、客户侧应用 | 通常成本更高，但并发和稳定性更好。 |
| 低成本分组 | 非关键任务、批量低优先级任务 | 价格更低，但可能有更明显的限流或波动。 |
| Claude / Gemini / 国产模型分组 | 指定模型族调用 | 不同模型族可能有独立倍率和权限。 |

> 如果同一个模型在不同分组价格不同，这是正常现象；应以模型页、令牌页和用量日志中的实际倍率为准。
