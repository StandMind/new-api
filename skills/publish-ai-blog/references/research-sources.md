# AI 博文研究来源

## 使用原则

1. 先找原始材料，再找独立解释，最后用社区讨论发现遗漏。
2. 同时记录“事件发生时间”和“页面发布时间”。转载日期不能代替原始发布日期。
3. 页面发生移动时，只在同一官方域名、官方代码组织或官方社交主页中寻找替代地址。
4. 社交账号、显示名和认证规则会变化。引用前从组织官网或已知官方资料反向确认身份。
5. 搜索结果摘要不能作为证据。打开原页面并核对正文、表格、脚注、更新时间和适用条件。

## 一级来源：论文、代码和标准

- arXiv 最近提交： [cs.AI](https://arxiv.org/list/cs.AI/recent)、[cs.CL](https://arxiv.org/list/cs.CL/recent)、[cs.LG](https://arxiv.org/list/cs.LG/recent)、[stat.ML](https://arxiv.org/list/stat.ML/recent)。检查版本历史、作者单位和补充材料。
- [OpenReview](https://openreview.net/)：核对会议状态、评审意见、作者回复和最终版本，不把投稿等同于录用。
- [Semantic Scholar](https://www.semanticscholar.org/) 与 [Google Scholar](https://scholar.google.com/)：用于追踪引用、相关工作和作者版本，不代替阅读论文。
- 论文附带的官方 GitHub、模型卡、数据卡和许可证：用于确认可复现性、依赖版本、权重许可和已知限制。
- 标准与安全文件：厂商 system card、NIST 文档、ISO/IEC 公告、监管机构原文和正式法律文本。

## 独立评测与数据来源

- [Artificial Analysis](https://artificialanalysis.ai/)：价格、速度、质量和基准对比。记录测试日期、模型版本和方法学。
- [Arena](https://arena.ai/)：人类偏好竞技场。说明投票样本、模型别名、置信区间和排行榜波动。
- [Stanford HELM](https://crfm.stanford.edu/helm/)：透明评测框架和场景化结果。
- [LiveBench](https://livebench.ai/)：随时间更新的模型评测。核对题集版本和污染控制声明。
- [SWE-bench](https://www.swebench.com/)：软件工程代理评测。区分 Verified、不同代理框架和厂商自报结果。
- [BigCodeBench](https://bigcode-bench.github.io/)：代码生成评测。核对模型、提示和执行设置。
- [Epoch AI](https://epoch.ai/)：训练计算、产业趋势和研究数据。
- [METR](https://metr.org/)：前沿模型能力、安全和长任务评测。
- [ARC Prize](https://arcprize.org/)：抽象推理竞赛、数据和方法说明。
- [Stanford AI Index](https://hai.stanford.edu/ai-index)：年度产业、研究、政策和经济数据。

将排行榜作为一个信号，而不是“最强模型”的充分证明。优先使用多个互补评测，并说明自报、闭源、提示优化、测试污染和方差限制。

## 社交媒体与人物言论

## 搜索模板

按当前日期替换日期和主题：

```text
site:openai.com/news "MODEL_OR_TOPIC" after:YYYY-MM-DD
site:anthropic.com/news "MODEL_OR_TOPIC"
site:deepmind.google/discover/blog "MODEL_OR_TOPIC"
site:ai.google.dev "MODEL_NAME" changelog
site:github.com/ORG/REPO releases "VERSION"
site:huggingface.co/ORG "MODEL_NAME" license
site:arxiv.org "PAPER_TOPIC" after:YYYY-MM-DD
"MODEL_NAME" system card filetype:pdf
"MODEL_NAME" pricing context window rate limits
"MODEL_NAME" benchmark methodology independent evaluation
"PERSON_NAME" interview transcript "CLAIM_KEYWORD"
site:x.com/ACCOUNT "CLAIM_KEYWORD" since:YYYY-MM-DD until:YYYY-MM-DD
```

为非英语来源分别使用中文、日文、法文、西班牙文、俄文和越南文关键词，再回到官方原文核对。

## 最小证据组合

- 模型发布：官方公告 + 模型卡或技术报告 + API/权重实际可用证据 + 独立评测或可靠媒体。
- API、价格或限制变化：官方文档或 changelog + 定价页 + 对应日期的可用性说明。
- 论文突破：论文最新版 + 作者代码或数据 + 独立评论、复现或相关工作。
- 人物言论：原始帖子、视频或文字稿 + 完整上下文 + 必要的组织回应或事实核对。
- 融资与商业数据：公司公告或监管文件 + Reuters、FT、Bloomberg 等独立来源。
- 政策与法规：正式法律或监管文本 + 机构解释 + 有资质的法律或政策分析。
